## Как проверить перед отправкой
Просто открой `index.html` в браузере (двойной клик). Всё должно работать локально без сервера — кроме отправки в Telegram, для которой нужны настроенные токен и chat_id из пункта 1.

## Важно про безопасность
Токен бота будет виден любому, кто откроет исходный код страницы (это обычное дело для маленьких личных проектов, но не используй для этого бота ничего важного — сделай отдельного, только для этой цели).
